# JJ — Jornal Jovem

Protótipo de portal de notícias voltado para jovens.

## Arquivos
- index.html — estrutura do site
- styles.css — identidade visual e responsividade
- script.js — busca, menu mobile, glossário, newsletter e interações

## Como executar
Abra `index.html` no navegador.

## Observação
As notícias são textos demonstrativos. As imagens usam URLs do Unsplash para o protótipo. Para um portal real, substitua o conteúdo por uma fonte editorial/CMS e utilize imagens com licença adequada.

## Direção visual
A interface foi inspirada em portais jornalísticos modernos, com hierarquia de manchetes, categorias, "Mais lidas", destaque de conteúdo e navegação por temas. A referência à Jovem Pan foi usada apenas como inspiração de experiência editorial, não como cópia visual.
